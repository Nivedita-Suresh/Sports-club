# 🏅 Sports Club – UI/UX Practice Website

This project is a **frontend-only website** built to practice and demonstrate UI/UX design skills using **HTML**, **CSS**, and **Bootstrap**. It simulates a website for a fictional sports club, featuring events like Football, Basketball, and an Annual Marathon.

> ⚠️ This site is for UI/UX practice only. No backend functionality is implemented. All forms are non-functional and for design showcase purposes only.

## 🚀 Features

- 🎨 Clean and modern UI
- 🏃‍♂️ Individual pages for each event (Football, Basketball, Marathon)
- 📋 Registration forms styled with Bootstrap
- 🌄 Background images with overlay content
- 📱 Responsive design using Bootstrap 4
- 🔗 Navigation bar with anchor links


## 🧠 What You Can Learn from This Project

- Using **Bootstrap 4** for grid layout and UI components
- Designing responsive sections and cards
- Building event landing pages with **hero sections**
- Styling transparent overlays over background images
- Creating basic navigation structures and static forms


## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap 4
